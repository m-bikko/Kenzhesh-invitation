# Схема вики

Obsidian-friendly база знаний проекта. Контент на русском, имена файлов на английском (kebab-case), технические термины не переводятся.

## Структура папок

```
wiki/
├── CLAUDE.md           # эта схема
├── index.md            # каталог всех страниц
├── log.md              # хронология операций
├── raw/assets/         # неизменяемые источники, картинки
└── pages/
    ├── entities/       # элементы системы: секции страницы, ассеты, интеграции
    ├── concepts/       # дизайн-система, поведение, контент
    ├── sources/        # саммари источников (бриф от заказчика и т.п.)
    └── analyses/       # решения и сравнения
```

## YAML frontmatter

```yaml
---
title: Название
type: entity | concept | source | analysis
tags: [тег1, тег2]
created: YYYY-MM-DD
updated: YYYY-MM-DD
sources: [пути или URL]
---
```

## Конвенции

- Связи через `[[wikilinks]]`; у каждой страницы минимум одна входящая ссылка (из `index.md`).
- `updated:` поднимать при каждом редактировании, даты в ISO.
- Не писать номера строк, секреты, git-историю.

## Операции

- **Ingest:** источник в `raw/` → саммари в `pages/sources/` → обновить затронутые страницы → `index.md` → `log.md`.
- **Update:** найти страницы → править → поднять `updated:` → `log.md`.
- **Query:** `index.md` → страницы → ответ; ценный ответ сохранить в `analyses/`.
- **Lint:** противоречия, устаревшее, сироты, broken links.
