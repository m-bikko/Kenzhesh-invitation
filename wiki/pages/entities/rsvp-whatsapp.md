# RSVP через WhatsApp

Секция «Келесіз бе?» на [[invite-page]]. Без бэкенда: форма собирает ответ и открывает `wa.me` с готовым текстом на номер организатора. Номер из [[client-brief]].

## Поля

- **Есіміңіз** (обязательно, до 80 символов)
- **Қатысуыңыз** (обязательно): Өзім келемін / Жұбайыммен келемін / Келе алмаймын. Варианта по умолчанию нет, чтобы гость выбрал осознанно.

Ошибки показываются под полями по-казахски и исчезают при вводе или выборе.

## Отправка

- Номер: константа `RSVP_WHATSAPP_PHONE = '77761618998'`.
- Текст: «Сәлеметсіз бе! Кенжештің 50 жас мерейтойына жауап:», затем строки «Есімі:» и «Жауабы:».
- `window.open(url, '_blank')`; если попап заблокирован, переход в той же вкладке.
- После этого форма заменяется на «Рақмет!» с кнопкой «Жауапты өзгерту».

## Ограничения

- Сообщение уходит, только когда гость сам нажмёт «Отправить» в WhatsApp.
- Ответы нигде не хранятся: сводку организатор ведёт по чату.
