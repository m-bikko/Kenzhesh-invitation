# Кенжеш · 50 жас — құпия шақыру

Одностраничный пригласительный сайт на казахском языке на юбилей-сюрприз (50 лет). Мобильная колонка 430px, по центру на десктопе. Статика без сборки: `index.html` + `assets/`.

Сделан на основе проекта «Нұрым & Карина» (свадебное приглашение), без git-истории.

- **Дата:** 10.10.2026 (сенбі), 13:00 (Астана, UTC+5)
- **Место:** Шаңырақ мейрамханасы, Астана, Еренқабырға көшесі, 13 ([2GIS](https://2gis.kz/astana/geo/9570784863323794/71.457423,51.147062))
- **Главное:** это сюрприз, гостей просят не рассказывать Кенжешу и не опаздывать

## Секции

0. **Печать** — полноэкранная «сургучная печать» с «50», тап открывает приглашение и заодно запускает музыку (жест пользователя снимает блокировку автоплея)
1. **Hero** — «КЕНЖЕШ», большое золотое «50», «ЖАС», дата, винил-кнопка музыки
2. **Шақыру** — «Құрметті қонақтар!» и текст приглашения
3. **Сюрприз** — просьба хранить секрет, «Кенжешке айтпаңыз»
4. **Кеш салтанаты** — 10 қазан, календарь октября с обведённым 10, время 13:00, блок «кешікпей келіңіз»
5. **Мекенжай** — Шаңырақ + кнопка «Картадан көру» (2GIS)
6. **Мерейтойға дейін** — живой обратный отсчёт
7. **Финал** — «Кенжешті бірге таңғалдырайық!»

## Музыка

`assets/music.mp3` — трек перенесён из свадебного проекта. Старт с отметки 2:05 (`MUSIC_START` в скрипте), зацикливается на неё же. Для юбилея стоит заменить файл и поправить `MUSIC_START`.

## Дизайн

Тёмный изумруд + золото, орнамент «қошқар мүйіз» (inline SVG `<symbol id="oyu">`). Шрифты Cormorant Garamond + Montserrat (Google Fonts), поддерживают казахскую кириллицу. Эмодзи из исходного текста заменены SVG-иконками (стиль lucide).

## Локальный просмотр

```bash
python3 -m http.server 8750
# открыть http://localhost:8750
```

## Деплой на Vercel

Импортировать репозиторий на [vercel.com/new](https://vercel.com/new): статический сайт, настройки не нужны.
